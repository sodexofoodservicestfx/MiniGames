# MiniGames

5 mini games that include 

1. Word scramble - Unscramble The StFX inspired Words
2. Guess the Building - Guess the StFX building by looking at the picture
3. 60 Second Challenge - Try to get as many questions correct in 60 seconds
4. Memory Match - Match the cards by flipping them 2 at a time
5. Higher or Lower - Guess which food has the higher Protein, Sugar or calories
